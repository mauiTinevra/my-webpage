How this was made

A pottery studio you can try before you book.

The brief: a quiet studio catalog for a wheel-throwing studio in Tempe, where the first job is class dates, prices and a seat. The proof point is a pot the visitor shapes by hand, drawn as generated SVG and named from its proportions.

Go and throw one

No. 01

Look

Three colors, split roughly sixty, thirty, ten.

Celadon carries the page. Iron black is the text, the rules, the wheel head and two full-width bands. Oxide rust is saved for the clay itself and for the small italic numerals, so the pot is the only large warm thing on the page.

Rust on celadon measures 4.3 to 1, a little short of the 4.5 needed for small text, so rust is only ever used for drawing or for type at 24 pixels and larger. Body text is iron black at 11.7 to 1. The quieter grey is the same black at 74 percent, 5.7 to 1.

Glaze celadon#cfe0d4, with a paler tint #dde9e0 for panels
Iron black#23211f
Oxide rust #a4472a

Display

Cormorant Garamond

Weights 400, 500 and 600 with two italics. Used for headings, class names and every number that matters, set with lining figures so prices read like entries in a kiln log.

Text

Karla, the variable cut

One file covers every weight. Running text is 17 pixels. Labels are 12 pixels, uppercase, tracked out. Both families are self-hosted from Fontsource, Latin subset only.

No. 02

The pot

Four points, one curve, seven bands.

  1. The state is seven numbers in centimetres: four radii, the height, and how far up the belly and shoulder sit. Dragging a handle or pressing an arrow key changes one or two of them inside sensible limits.
  2. A monotone cubic (Fritsch and Carlson) is fitted through the four points and sampled 45 times. It never overshoots a control point, so the wall cannot bulge past a handle.
  3. The profile is turned round the centre line. Each ring is drawn as an ellipse squashed to a fifth, as if seen from a little above. A band is the part of the front surface from one fraction of the radius across to the right edge. Seven bands in seven tones of the clay color are painted over each other from left to right.
  4. A perfectly round pot looks the same at every angle, so the turning is shown by things that are not symmetrical: a spiral throwing line, eighteen iron specks and two bat pins on the wheel head. Only those are redrawn on each frame.
  5. The name comes from two ratios, height to width and rim to widest point, plus the real height. The clay weight is the surface area times a 7 millimetre wall, plus a base, at 1.75 grams per cubic centimetre, with a quarter added for trimming.
// A point on the lathed surface. u runs from -1 (left edge)
// to 1 (right edge) across the front of the pot.
function pt(r, y, u) {
  return [CX + u * r * S,
          BASE - y * S + K * r * S * Math.sqrt(1 - u * u)];
}

// One shaded band: from u0 across to the right edge.
function bandPath(u0) {
  var pts = [], top = prof[N], bot = prof[0], i, u;
  for (i = 0; i <= N; i++) pts.push(pt(prof[i][0], prof[i][1], u0));
  for (i = 1; i <= 10; i++) { u = u0 + (1 - u0) * i / 10;
                             pts.push(pt(top[0], top[1], u)); }
  for (i = N - 1; i >= 0; i--) pts.push(pt(prof[i][0], prof[i][1], 1));
  for (i = 1; i < 10; i++) { u = 1 - (1 - u0) * i / 10;
                            pts.push(pt(bot[0], bot[1], u)); }
  return 'M' + pts.map(xy).join('L') + 'Z';
}

Each handle is a focusable SVG group with a slider role and a spoken value such as "6 in across, 4½ in above the wheel". Pointer events cover mouse, pen and touch, and only the handles block scrolling, so a thumb can still move the page past the drawing. The wheel turns while the clay is being shaped and stops soon after. With reduced motion switched on it stays still unless the visitor presses "Keep the wheel turning".

No. 03

Critique

Three passes with fresh screenshots.

Pass one

Found

Font preloads threw errors when the page was opened from disk. The booking button sat below the first screen. The drawing floated in a tall empty frame. Handle labels vanished where they crossed the pot. A plate looked like a dark hole.

Changed

Removed the preloads. Moved the button up under the opening paragraph. Enlarged the pot and stood the drawing on the bottom of its frame. Gave labels a pale outline. Upgrade: the inside of the pot now lightens as the form gets shallower, so a plate faces the light.

Pass two

Found

The class table wrapped "6 weeks" on to two lines. The firing chart was small with a void beneath it. A stray rule showed under the dark band. The footer email ran past its column.

Changed

Rebalanced the table columns. Enlarged the chart type and added this week's firings below it. Removed the rule and widened the last footer column. Upgrade: a dotted hairline now runs from the inch ruler to the lip, the way a catalog plate marks a height.

Pass three

Found

On a phone the class times ran into the seats column, the chart labels were about 7 pixels tall, the menu button touched the header rule and the footer email broke in the middle of a word. Two rust numerals were under the size where rust has enough contrast.

Changed

Laid out each class as its own small grid on phones, scaled the chart type up, padded the header and gave the footer contact list a full row. Raised the numerals to 24 pixels. Upgrade: the wheel head carries a faint reflection of the foot of the pot, because a working wheel is wet.

No. 04

Limits

One honest limitation.

The page only knows five names. A squat form with a closed-in rim is really a jar, and here it is called a bowl. The drawing is also a shortcut: the outline is the profile itself, not the true outline of a turned solid seen from above, which shows on very wide, shallow forms where the handles also sit close together.

The booking form checks what you type and prints a slip, but it sends nothing. Class dates are worked out from the visitor's clock in Phoenix time, and seat counts are fixed numbers.
